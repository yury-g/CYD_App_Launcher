CYD Pulse Dashboard

Install the current PulseSensor dashboard firmware on an ESP32 Cheap Yellow Display from a browser.

Flash Firmware

Connect the CYD over USB, use Chrome, Edge, or Opera, then choose the serial port when prompted.

This browser does not support WebSerial. Use Chrome, Edge, or Opera.

Wire The PulseSensor

PulseSensor Wire CYD Connection
RED (+V) 3.3V on CN1
BLACK (GND) GND on P3 or CN1
PURPLE (Signal) GPIO 35 on P3
Use 3.3V, not 5V. The PulseSensor signal is expected on GPIO 35.

What You Should See

  • Live waveform in cyan while searching and white when qualified.
  • BPM, IBI, signal quality, and detector re-arm count.
  • Animated heart, rear red LED blink, and heartbeat tone on qualified beats.
  • Touch volume controls in the header.

Arduino IDE One-File Sketch

The firmware is intentionally kept in one Arduino sketch file: CYD_App_Launcher.ino.

1. Download CYD_App_Launcher.ino.
2. Make a folder named CYD_App_Launcher.
3. Put CYD_App_Launcher.ino inside that folder.
4. Open CYD_App_Launcher.ino in Arduino IDE.
5. Install the ESP32 board package.
6. Install TFT_eSPI, PulseSensor Playground, and XPT2046_Touchscreen.
7. Configure TFT_eSPI for the CYD display.
8. Select an ESP32 board and upload at 115200.
